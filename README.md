# Digital Ethical Twin (DET) - Omron Robot

## 🎯 Projet de thèse
**Doctorant** : Chahrazad Sehrani  
**Laboratoire** : CRAN - Université de Lorraine  
**Encadrantes** : Hind BRIL-EL HAOUZI, Yinling LIU

## 📋 Objectif
Intégration d'un raisonnement éthique basé sur LLM dans un jumeau numérique 
pour robot mobile Omron.

## 🛠️ Stack technique
- FIWARE Orion Context Broker (Digital Twin)
- Python 3.11+
- Docker Compose
- LLM API (Anthropic Claude / OpenAI GPT)

## 📅 Timeline
- Phase 1 (Semaines 1-5) : PoC FIWARE + LLM
- Livrable : Article IFAC (7 semaines)
